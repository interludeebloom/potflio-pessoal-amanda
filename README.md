> Meu portfólio pessoal — onde código, dados e uma estética retrô-cyber se encontram.

---

## 🖥️ Sobre o projeto

Este é o meu portfólio pessoal, criado para apresentar minha trajetória, projetos e habilidades como desenvolvedora.

O **design e o conceito visual são de minha autoria**, com uma identidade inspirada na estética **retrô/cyber de computadores antigos** — janelas de sistema, ícones pixel-art, cursores old-school — traduzida principalmente em tons de **amarelo** e **azul**.

O código da interface foi **gerado com o auxílio da ferramenta [Lovable](https://lovable.dev)**, mas toda a **direção de design, a curadoria das imagens e as referências visuais** utilizadas no projeto são minhas.

---

## ✨ Autoria e processo

O desenvolvimento deste portfólio seguiu um processo estruturado, do conceito ao código:

## 🚀 Como rodar o projeto localmente

**Pré-requisitos:** ter o [Node.js](https://nodejs.org/) e o npm instalados.

```sh
# 1. Clone o repositório
git clone <url-do-repositorio>

# 2. Acesse a pasta do projeto
cd <nome-da-pasta>

# 3. Instale as dependências
npm install

# 4. Rode o ambiente de desenvolvimento
npm run dev
```

O projeto ficará disponível em `http://localhost:8080`.
